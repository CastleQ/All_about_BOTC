# BOTC 위키 한글번역 자료 — 색인

Blood on the Clocktower(시계탑에 흐른 피) 공식 위키를 한국어로 옮긴 비공식 번역(https://castleq.github.io/botc-wiki-ko/)의 전체 내용이다. 캐릭터 이름·능력·용어는 한국 정발 표기를 따른다.

## 이 자료를 읽는 방법 (AI용)

1. 먼저 이 색인을 본다. 캐릭터의 유형·에디션·능력은 아래 표만으로 답할 수 있다.
2. 진행 방법·예시·팁·블러핑·징크스 같은 자세한 내용은 표의 "파일" 칸에 적힌 파일 하나만 연다.
3. 규칙·용어·전략 질문은 아래 "문서" 표에서 알맞은 파일을 연다. 상태(취함·중독·집착)는 rules/states.md, 용어 뜻은 game-info/glossary.md.
4. 캐릭터 아이콘 이미지 주소: https://castleq.github.io/pocket-grimoire/img/official/<id>_0.webp (<id>는 표의 id). 각 캐릭터 파일 맨 위 icon 칸에도 있다.
5. 영어 이름으로 물어도 표의 "영문" 칸으로 찾는다. 캐릭터는 이름이 아니라 id로 구분된다(예: acrobat = 기예꾼, juggler = 곡예사).
6. 불필요한 토큰사용을 막기 위해 ALL.md 파일은 사용자 요청이 없다면 절대로 읽지 않는다.
