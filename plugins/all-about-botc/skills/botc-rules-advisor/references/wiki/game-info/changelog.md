# 변경 이력 (Changelog)

실험 캐릭터는 아직 소속된 스크립트가 없으므로, 캐릭터가 작동하는 방식의 문제를 해결하거나 더 재미있게 만들기 위해 일부 캐릭터 설명, 징크스, 연감 항목이 수정될 수 있습니다.

변경 사항은 공식 앱의 정기 업데이트와 함께 발표되며, 위키에도 그에 맞춰 반영됩니다. 이 변경 사항들은 앞으로 다시 수정되거나 바뀔 수 있습니다. 이 페이지는 2024년 5월부터 이루어진 모든 변경 사항의 기록입니다.

## 2024년 11월 8일



### 능력 문구 변경



#### 알사히르

- 이전 → 하루에 한 번, 공개적으로 누가 하수인이고 악마인지 추측합니다. 성공하면 선한 팀이 승리합니다.
- 현재 → 매일 낮, 공개적으로 누가 하수인이고 악마인지 추측합니다. 성공하면 선한 팀이 승리합니다.

#### 아가씨

- 이전 → 모든 하수인은 당신이 게임에 참여한다는 사실을 압니다. 하수인이 당신을 공개적으로 추측해 내면(여러명 중 단 1번만 가능), 당신이 속한 팀이 패배합니다.
- 현재 → 모든 하수인은 아가씨가 게임에 참여한다는 사실을 압니다. 하수인이 당신을 공개적으로 추측해 내면(여러명 중 단 1번만 가능), 당신이 속한 팀이 패배합니다.

#### 농부

- 이전 → 당신이 밤에 사망한다면, 생존한 선한 플레이어 1명이 농부가 됩니다.
- 현재 → 당신이 밤에 사망하면, 생존한 선한 플레이어 1명이 농부가 됩니다.

#### 왕

- 이전 → 매일 밤, 사망한 플레이어 수가 생존한 플레이어 수 이상이라면, 생존한 캐릭터 1명을 알게 됩니다. 악마는 당신이 누구인지 알고 있습니다.
- 현재 → 매일 밤, 사망한 플레이어 수가 생존한 플레이어 수 이상이라면, 생존한 캐릭터 1명을 알게 됩니다. 악마는 당신이 왕이라는 사실을 알고 있습니다.

#### 야경꾼

- 이전 → 게임당 1번, 밤에 플레이어 1명을 선택합니다: 그는 당신이 누구인지 알게 됩니다.
- 현재 → 게임당 1번, 밤에 플레이어 1명을 선택합니다: 그는 당신이 야경꾼임을 알게 됩니다.

#### 역병 의사

- 이전 → 당신이 사망한다면, 이야기꾼은 하수인의 능력을 얻습니다.
- 현재 → 당신이 사망하면, 이야기꾼은 하수인의 능력을 얻습니다.

#### 밀고자

- 이전 → 하수인들은 참여하지 않는 캐릭터 3개를 알고 시작합니다.
- 현재 → 각 하수인은 블러핑용 캐릭터 3명을 알게 됩니다.

#### 재상

- 이전 → 모두가 당신이 누구인지 압니다. 당신은 낮에 사망할 수 없습니다. 선한 팀이 투표했다면, 지목 대상을 즉시 처형할 수 있습니다.
- 현재 → 모두가 당신이 재상임을 알게 됩니다. 당신은 낮에 사망할 수 없습니다. 선한 팀이 투표했다면, 지목 대상을 즉시 처형할 수 있습니다.
